mailcli setup and inbox
========================

Setup is the real wizard (mailcli.setup, which `python -m mailcli setup` calls).
The provider chosen below is Gmail. The app password was typed at the hidden
prompt and is not in this transcript. It was kept in the credential store for
that process, not written to gmail.toml. On Windows that store is Credential
Manager via the keyring package. This VM's Secret Service prompt does not
unlock, so the capture used an in-memory keyring backend.

$ python -m mailcli setup

Choose a mail provider. mailcli will fill in the servers.

  1  Gmail
  2  Outlook, Hotmail, or Live
  3  Yahoo
  4  iCloud
  5  Proton
  6  Custom server

Provider number: 1

Gmail
  IMAP  imap.gmail.com:993  SSL
  SMTP  smtp.gmail.com:465  SSL
Gmail rejects your normal account password for IMAP and SMTP.
Turn on 2-Step Verification, then create an app password:
  https://myaccount.google.com/apppasswords
Google's own steps: https://support.google.com/accounts/answer/185833
The app password is 16 letters. Spaces in it do not matter.
SMTP on port 587 with STARTTLS also works; this preset uses port 465 with SSL.
If you would rather use OAuth, pass --oauth-client-id from a Google Cloud
client you registered yourself. An app password is the usual path.

Email address: you@gmail.com
Account name [you]: home
App password: (typed, not echoed)

Saved account home (Gmail) to gmail.toml
The password or token is in the OS credential store, not in that file.
home is the default account.

gmail.toml after setup (no password, no token):

default_account = "home"

[accounts.home]
provider = "gmail"
user = "you@gmail.com"
imap_host = "imap.gmail.com"
imap_port = 993
imap_security = "ssl"
smtp_host = "smtp.gmail.com"
smtp_port = 465
smtp_security = "ssl"
auth = "password"
folder = "INBOX"
tls_verify = true

Inbox
-----

The mailbox below is GreenMail 2.1.15 on this machine, configured as a custom
account (IMAPS 127.0.0.1:3993, SMTPS 127.0.0.1:3465, tls_verify = false).
No Gmail, Outlook, Yahoo, iCloud, or Proton account was contacted.
MAILCLI_PASSWORD was set for that local account and is not shown.
Six messages were delivered over SMTP. "Re: design review" was already read.
